# Herramientas de MyPlanificador

- `pins.py`: genera pines 1000x1500 (estilo de la marca: fondo de color, título Poppins Bold, píldora "Descarga instantánea" y logo mP). Rutas absolutas del repo en `/home/claude/myplanificador-media`; ajusta `SP` a tu carpeta temporal.
- `music.py`: sintetiza `xmas.wav` (Jingle Bells, dominio público, caja de música) y `neutral.wav` (arpegio), 16 s.
- `frames.py`: pasa pines a lienzo vertical 1080x1920 y crea la tarjeta final `end.jpg`.
- `mk_reels.sh`: monta Reels de ~14 s (2 imágenes con zoom + tarjeta final + música) y añade música a vídeos mudos.

Los vídeos para Instagram/TikTok van en `videos/reels/` y se enlazan por raw.githubusercontent.com para Metricool.
